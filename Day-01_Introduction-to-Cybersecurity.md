## 2. Installation and Setup

I installed and explored the following tools:

- **Kali Linux:** A Linux distribution widely used for cybersecurity learning and security testing.
- **VirtualBox:** Software that allows operating systems to run inside virtual machines.

These tools helped me prepare an environment for practising Linux commands and completing cybersecurity exercises.

## 3. Basic Linux Commands

I learned and practised the following Linux commands:

| Command | Description |
| `ls` | Lists files and directories. |
| `cat` | Displays the contents of a file. |
| `cd` | Changes the current directory. |
| `find` | Searches for files and directories. |
| `grep` | Searches for specific text in files or command output. |

These commands are useful for navigating the Linux terminal, managing files, and searching for information.
