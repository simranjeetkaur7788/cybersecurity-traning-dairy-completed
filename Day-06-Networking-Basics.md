## 2. Topics Learned

### A. What Is Networking?

Computer networking means connecting two or more devices so they can communicate and share information.

Examples include computers connected in a college laboratory and mobile phones connected to Wi-Fi.

### B. What Is the Internet?

The internet is a global network that connects many smaller networks. It allows devices to exchange information and access online services.

### C. Identifying Devices on a Network

Devices use different types of addresses to communicate.

**IP Address:** An Internet Protocol address identifies a device on a network.

Example:
```text
192.168.1.10
```

**MAC Address:** A Media Access Control address identifies a network interface.

Example:
```text
A4:C3:F0:85:AC:2D
```

### D. Ping Command

The `ping` command helps test network connectivity by sending ICMP Echo Request packets and checking for replies.

**Linux command:**
```bash
ping -c 4 8.8.8.8
```

**Windows command:**
```cmd
ping 8.8.8.8
```

This command can help check whether a destination responds to network requests.

### E. Introduction to LAN

LAN stands for Local Area Network. It connects devices within a limited geographical area, such as a home, office, or college laboratory.

**Examples:**
- Computers connected in a college lab.
- Devices connected to a home Wi-Fi network.
- Computers sharing resources in an office.
