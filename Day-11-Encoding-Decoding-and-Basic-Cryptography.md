## 1. Objective
The objective of this training session was to understand the basic concepts of encoding, decoding, and cryptography. I learned how information can be represented in different formats and how cryptography helps protect sensitive information.

## 2. Introduction
During this session, I studied how computers represent and process information. Encoding, decoding, encryption, and decryption are important concepts in cybersecurity. They are used in data communication, information processing, and protecting confidential data.

## 3. Encoding
Encoding is the process of converting data from one format into another format so that it can be stored, processed, or transmitted correctly.

For example, Base64 is a common encoding method that converts data into a set of characters that can be easily transmitted through systems that support text.

Encoding is not designed to keep information secret. Anyone who knows the encoding method can usually decode the data without a secret key.

## 4. Decoding
Decoding is the process of converting encoded information back into its original form.

For example, if a text message is converted into Base64, decoding can convert the Base64 representation back into the original text.

Encoding and decoding are commonly used in data transmission, web applications, and computer systems.

## 5. Basic Cryptography
Cryptography is the study of techniques used to protect information. It helps maintain confidentiality, integrity, and authenticity.

The main concepts I learned were:

- **Plaintext:** The original readable information.
- **Ciphertext:** The information after it has been encrypted.
- **Encryption:** The process of converting plaintext into ciphertext.
- **Decryption:** The process of converting ciphertext back into plaintext.
- **Key:** Information used by a cryptographic algorithm to encrypt or decrypt data.

## 6. Difference Between Encoding and Hashing
Encoding can be reversed through decoding. Hashing, however, produces a fixed-length digest from input data. A secure hash function is designed to make it computationally impractical to recover the original input from the digest.

Hashing is commonly used to verify file integrity and support secure password storage systems.
