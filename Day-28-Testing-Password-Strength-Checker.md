# Day 28: Testing the Password Strength Checker

**Date:** 28 July 2026  
**Topic:** Password Strength Evaluation

## 1. Introduction
On this day, I tested the Password Strength Checker module of my Cyber Security Toolkit to understand how it evaluates passwords based on their characteristics.

## 2. Practical Work
I tested different password examples with varying lengths and combinations of uppercase letters, lowercase letters, numbers, and special characters. I observed how these characteristics affected the strength assessment.

## 3. Observations
I learned that longer, unique, and unpredictable passwords are generally more secure. Using different character types can help, but common words and predictable patterns should be avoided.

## 4. Conclusion
This practical session helped me understand how password strength evaluation works. I also learned the importance of using strong, unique passwords and enabling multi-factor authentication for better account security.
