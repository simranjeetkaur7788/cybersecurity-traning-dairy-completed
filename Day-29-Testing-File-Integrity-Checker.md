# Day 29: Testing the File Integrity Checker

**Date:** 29 July 2026  
**Topic:** File Integrity Verification Using Hashes

## 1. Introduction
On this day, I tested the File Integrity Checker module of my Cyber Security Toolkit. The purpose was to understand how file hashes help identify changes in file contents.

## 2. Practical Work
I reviewed how the program generates a hash for an original file and compares it with the hash of another file. I learned that if the file contents change, the hash value will normally change as well.

## 3. Observations
- If the file remains unchanged, the hashes should match.
- If the file is modified, the hashes will normally differ.
- SHA-256 is a commonly used cryptographic hash algorithm for integrity checking.

## 4. Conclusion
This practical session helped me understand how hashing can be used to check file integrity. I learned that comparing hashes helps detect unexpected changes in files.
